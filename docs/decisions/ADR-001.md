### Keputusan Ronde 23 (2026-10-08) — settlement buy (TASK-005): fee & residual

> Ditemukan saat implementasi tiket 07; dua kontradiksi SSOT diselesaikan. Detail: [contracts/market.md](../contracts/market.md) §3/§4a.

- **Fee masuk treasury di settlement (bukan akumulasi + `withdraw_fees`).** [features/payments.md](../features/payments.md)
  §Algoritma, [01-PRD.md](../01-PRD.md) §13, ADR-005 §Decision, dan [contracts/market.md](../contracts/market.md) §3 semuanya
  menyatakan `distributions = payout + [(seller, seller), (treasury, fee)]`; hanya baris ringkasan
  akuntansi/asset-inventory/TC-047 yang menyebut model dua langkah. **Dipilih transfer langsung** —
  market tidak pernah memegang dana fee, sehingga temuan **M7** (akuntansi solvensi fee vs escrow vs
  storage) hilang dan tidak ada honeypot saldo. TC-047 dialihkan ke `update_fee_bps`/`update_treasury`.
- **Residual seller bukan dust.** Aturan `sisa ∈ {0,1} yocto` (INV-002) berasal dari model tutorial
  (RESEARCH.md §10.5: `nft_transfer_payout` mengembalikan seluruh distribusi). NearSea memakai model
  berbeda — koleksi mengembalikan **hanya royalti**, market menambahkan seller sebagai residual —
  sehingga `max_pay − Σpayout` = **proceeds seller** (wajar besar). Aturan `sisa ≤ 1` **dibatalkan**;
  yang divalidasi tetap `Σpayout ≤ harga − fee`, `amount > 0`, `1 ≤ len ≤ 10`.
- **`process_purchase` (callback dual-verification) ditambahkan** — verifikasi ownership+approval saat
  settle tidak bisa sinkron (view XCC = receipt terpisah), jadi stale diputuskan di callback: refund
  penuh + event `market_stale_detected`, **bukan** panic tx (dana buyer tidak pernah tertahan).

### Keputusan Ronde 7–12 tanya-jawab (2026-10-01)

- **Positioning**: marketplace NFT terbuka umum — "OpenSea-nya NEAR". Target: trader, kreator, newcomer, komunitas NEAR (semua). Value prop: gas murah+cepat, fee 2%+royalti on-chain, ekosistem NEAR, UX simpel. Metric bisnis ditunda sampai mendekati mainnet.
- **UX**: top-nav ala OpenSea; halaman inti + leaderboard + settings + onboarding guide; responsive **setara penuh**; Home = search + grid listing.
- **Model listing (ADR-007, hasil riset)**: **approval non-custodial ala OpenSea/Seaport** — NFT tetap di wallet seller; listing permanen; stale (token pindah di luar market) → auto-stale + sembunyi. Offer pada semua token (listed/tidak). Fee 2% konsisten di semua jalur.
- **Launchpad (ADR-008)**: ala OpenSea Studio — creator bebas definisikan phase mint (berapa pun; tiap phase: harga, alokasi, allowlist opsional, waktu); allowlist disimpan **on-chain set**; koleksi baru langsung tampil; supply bebas tanpa cap; storage mint dibayar pemicu mint.
- **API**: REST JSON + cursor pagination; write (report/profil/admin) pakai **signature wallet** (challenge nonce); admin = allowlist di DB + login wallet, panel /admin.
- **Ops**: timeline fleksibel (done-when); demo per milestone; git branch per fitur + conventional commits; alert admin via **bot Telegram**; tanpa webhook keluar di v1.
